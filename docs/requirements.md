# Analytical brief

Proposed portfolio requirements, not records of stakeholder interviews.

| Audience | Question | Output and acceptance |
|---|---|---|
| Service manager | How does an area compare with Liverpool and England? | Select any of 61 MSOAs; show the numerator, correct denominator, share and benchmark difference. |
| Analyst | Can the figures be reproduced? | Source register, checked source snapshot, explicit SQL views, automated checks and deterministic exports. |
| Insight team | Where do indicators vary within the city? | Selectable map, rankings and sortable area table on one consistent geography. |
| Decision maker | What can we conclude, and what needs more work? | Short findings note separating observed differences from possible next questions. |

## Completion criteria

- Three indicators across all 61 areas, plus published city and England benchmarks.
- Two interactive report pages: area explorer and comparisons.
- Counts and percentages match checked SQL outputs; all controls work with zero search results.
- Source period and boundaries visible; unknown or malformed source values cause a failed build.
- Native Power BI model/report provided with explicit Desktop verification status.
- No claimed current demand, causal effects, stakeholder work or measured savings.

## Relevance to a data analyst role

This project demonstrates joining multiple official feeds, SQL analysis, geographical reporting, benchmark comparisons, data-quality controls and communicating findings. It complements application-governance and website-analytics examples with a public-data case study.
